# Vertushka

Простой плеер для диджея на мероприятиях (Windows 11). Всё на русском, без лишнего.

C# · WPF · .NET 8 · [NAudio](https://github.com/naudio/NAudio) · установщик Inno Setup 6.

## Возможности
- **Проекты → разделы → треки.** Раздел — обычная папка на диске (`Музыка\Vertushka\...`); быстрое добавление треков перетаскиванием.
- **Очередь «Далее»**, затухание и плавный переход в конце трека, «Петля», «Поклон» (музыка тише на время речи).
- **Волна трека** по реальному профилю громкости, перемотка кликом, **до 4 меток** на трек (F1–F4).
- **Предпрослушивание в наушниках** на отдельном выходе.
- **Метки к ближайшему тихому месту:** обычные метки и «Начало/Конец» обрезки сами сдвигаются в самую тихую точку рядом (переключатель, по умолчанию включено).
- **Выбор нескольких треков**, перенос между разделами и порядок перетаскиванием.
- **Обрезка трека метками прямо во время прослушивания:** «Начало» и «Конец» ставятся кнопками на волне, вне меток затемнено, трек играет строго между ними; «Сбросить обрезку» возвращает целиком. Файл не меняется, обрезанный кусок можно сохранить отдельным файлом (mp3 — без потери качества).
- Запись с микрофона (отдельно или поверх музыки), кнопки-джинглы, мини-окно поверх программ.
- Оформление «Графитовый туман»: тёмная, светлая и «авто» темы.

## Сборка
Нужен .NET 8 SDK. Запуск без установки:

```
dotnet run -c Release --project src
```

Установщик (нужен Inno Setup 6): см. `build.bat` (версия в `version.txt`).
